## Usage rules

- One row per testable requirement or logically separable control.
- Link to exact approved source and current version.
- Do not mark “Pass” without reproducible evidence for the release build.
- Update when requirements, design, tests, sources, or risks change.
- Critical requirements require named human approval and cannot be closed only by AI.
